# Lock in ⚡️

A tiny, cute to-do list for focusing. Add things you gotta do, drag to reorder, check them off.

**Try it:** https://dianakarp.github.io/lockin/

## Features

- Add tasks and drag the grip handle to reorder them
- Check off tasks (the 5 most recent completions stay in the "done" section)
- Swipe left on a task to delete it
- A random cute (and a little Blue Lock) phrase on your completed list
- Works on iPhone: open it in Safari, then Share → Add to Home Screen

## Privacy

Your tasks never leave your device. They're saved in your browser's `localStorage`, not on a server, so nobody (including this repo) can see your list. The flip side is that clearing Safari's website data erases it.

## How it's built

A single `index.html` with no frameworks, no build step and no dependencies. Open the file in a browser and it works.
